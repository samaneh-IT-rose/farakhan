# تصمیم‌های باز نیازمند تأیید مالک محصول

طبق سند PRD، موارد زیر باید توسط مالک محصول تأیید شوند. همه پیش‌فرض‌ها
**متمرکز و قابل‌تغییر** پیاده‌سازی شده‌اند (فایل `.env` یا `app/core/config.py`
و `app/core/constants.py`) و با تغییر تنظیم، رفتار برنامه بدون تغییر کد عوض می‌شود.

| # | موضوع | پیش‌فرض فعلی | تنظیم/محل تغییر |
|---|---|---|---|
| ۱ | گزینه‌های دقیق وضعیت سربازی و الزام کارت پایان خدمت | ۴ گزینه (پایان خدمت، معافیت دائم، پزشکی، موقت/کسر خدمت)؛ وضعیت سربازی برای مردان الزامی، کارت پایان خدمت اختیاری | `MILITARY_STATUS_OPTIONS` در constants؛ `REQUIRE_MILITARY_STATUS_FOR_MALE`، `REQUIRE_MILITARY_CARD_FOR_MALE` |
| ۲ | فهرست گزینه‌های مدرک تحصیلی | دیپلم، کاردانی، کارشناسی، ارشد، دکتری | `EDUCATION_DEGREE_OPTIONS` |
| ۳ | ماهیت «پروانه فعالیت مرکز» | وضعیت انتخابی (دارای پروانه/در حال دریافت/فاقد) + توضیح اختیاری + فایل اختیاری | `LICENSE_STATUS_OPTIONS` |
| ۴ | شرایط اجباری‌بودن توضیحات پروانه | غیراجباری | `REQUIRE_LICENSE_DESCRIPTION` |
| ۵ | الزام مدارک مالکیت برای ملکی/استیجاری | غیراجباری | `REQUIRE_PROPERTY_DOCUMENTS` |
| ۶ | فایل‌های همیشه اجباری | هیچ‌کدام اجباری نیست | `REQUIRED_FILE_FIELDS` |
| ۷ | تک‌فایلی یا چندفایلی بودن هر فیلد | تک‌فایل؛ ارسال فایل تکراری برای یک فیلد رد می‌شود | رفتار در `submission_service` |
| ۸ | منبع رسمی استان‌ها و شهرستان‌ها | seed اولیه از داده مرکز آمار ایران (مخزن `sajaddp/list-of-cities-in-Iran`)، idempotent و قابل به‌روزرسانی | `app/db/seed_locations.py` + `seed_data/iran_locations.json` |
| ۹ | نقش‌های مجاز برای دیدن اطلاعات و کد ملی | فقط نقش واحد «مدیر»؛ کد ملی برای مدیر کامل نمایش داده می‌شود. تابع `mask_national_code` برای نقش‌های محدود آینده آماده است | `app/api/deps.py`، `utils/national_code.py` |
| ۱۰ | روش احراز هویت مدیران | JWT با حساب واحد از متغیرهای محیطی | `ADMIN_USERNAME`، `ADMIN_PASSWORD`، `ACCESS_TOKEN_EXPIRE_MINUTES` |
| ۱۱ | پیامک یا ایمیل تأیید | پیاده‌سازی نشده (خارج از محدوده نسخه پایه) | — |
| ۱۲ | مدت نگهداری داده و روش حذف/ناشناس‌سازی | حذف دستی توسط مدیر؛ سیاست نگهداری تعریف نشده | — |
| ۱۳ | متن نهایی قوانین، رضایت و حریم خصوصی | فقط ثبت `terms_accepted` و زمان آن؛ متن نهایی با فرانت‌اند نمایش داده می‌شود | — |
| ۱۴ | ثبت چند فرم با یک کد ملی | مجاز (روی کد ملی قید یکتا نیست) | مدل `Submission.national_code` |

## رفتارهای انتخابی مستندشده

- برای متقاضی **زن**، فیلدهای سربازی به‌جای رد شدن، بی‌صدا null می‌شوند.
- تاریخ تولد نامعتبر/آینده/غیرمعقول (خارج از بازه ۱۲۵۰ تا ۱۵۰۰ شمسی) رد می‌شود.
- سقف سن (`MIN_AGE_YEARS`) و سقف شمارنده‌ها (`MAX_COUNTER_VALUE`) پیش‌فرض **غیرفعال**‌اند تا قاعده تجاری بدون تأیید اعمال نشود.
- نوع فایل فقط با امضای محتوایی پذیرفته می‌شود؛ MIME اعلامی کاربر نادیده گرفته می‌شود.
- فیلد فایل ناشناخته یا تکراری → خطای 422 با پیام فارسی.
- `Idempotency-Key` در حافظه (تک‌نمونه‌ای) نگهداری می‌شود؛ در استقرار چندنمونه‌ای باید به Redis منتقل شود.
